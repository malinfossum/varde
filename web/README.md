# Varde web

The Varde web frontend — a bilingual (Norwegian/English) search UI for the API, built with
Vite, React and TypeScript.

## Run locally

```bash
npm install
npm run dev
npm test
```

`VITE_API_URL` defaults to `http://localhost:5005`; override it to point at a different API
instance.
